Seguridad

Credenciales y recuperación del panel

Esta sección concentra toda la seguridad del panel: cambio de contraseña, preguntas de seguridad y recuperación segura del acceso.

Cambiar contraseña

Clave del admin

Actualizá la clave del panel sin exponerla en frontend. Al guardarla, se cierran las sesiones activas y el backend exige volver a ingresar.

Elegí una clave nueva con al menos 7 caracteres que combine letras y números. Al confirmarla, el panel te pedirá ingresar otra vez.

Preguntas de seguridad

Recuperación segura

Guardá tres respuestas cifradas para recuperar el acceso sin exponer datos en el navegador ni en el repositorio.

Recuperación pendiente

Todavía no configuraste las preguntas de seguridad. Completalas para habilitar la recuperación segura del panel.

Las respuestas se guardan con hash seguro y solo se usan para validar la recuperación. No quedan visibles después de guardarlas.

Recuperación

Cómo funciona

Si olvidás la clave, desde la pantalla de acceso podés entrar a “Recuperar contraseña”, responder correctamente las 3 preguntas y definir una nueva contraseña. El sistema invalida las sesiones anteriores automáticamente.

Recuperar contraseña

Recuperá el acceso al panel

Respondé correctamente las preguntas de seguridad para habilitar una nueva contraseña.

La recuperación queda habilitada solo si las 3 respuestas coinciden con las que configuraste previamente.
