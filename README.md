# Estudiantes TBÓ

Landing premium profesional para el gimnasio Estudiantes TBÓ.

## Contenido

- `index.html`: estructura principal del sitio
- `style.css`: estilos y responsive
- `script.js`: animaciones e interacciones
- `assets/`: logo e imágenes reales del gimnasio

## Publicación

Este sitio está pensado para publicarse con GitHub Pages.

Una vez configurado el repo remoto, la web quedará disponible en la URL pública del proyecto y se actualizará automáticamente cada vez que se haga `push` a la rama publicada.
